# Wrist PPG Heart-Rate Estimation

Estimating heart rate from a wrist PPG sensor and accelerometer during daily activities,
using the PPG-DaLiA dataset (Reiss et al., Sensors 2019). Ground truth comes from chest ECG.

Status: in progress.

## Data
Download PPG-DaLiA from the UCI Machine Learning Repository and place it next to this folder
as `../ppg+dalia/`. The data is not included in this repository.
